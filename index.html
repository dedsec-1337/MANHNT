The loop

Five stages. One referee.

  1. 1

    Create a room

    The host sets duration, zone, head start and auto-ping.

  2. 2

    Join

    Everyone enters the 6-letter code. The host assigns Seeker or Runner.

  3. 3

    Head start

    Runners run. Seekers wait.

  4. 4

    Hunt

    Reveals land on a timer. Tags happen face to face.

  5. 5

    Result

    All runners caught: seekers win.

    Timer hits zero: runners win.

The mechanics

Mechanics

Auto-ping reveals

Pins freeze between pings.

Every 2 or 5 minutes the app snapshots runner positions. Seekers see those pins and nothing else until the next ping. Scroll to run the clock.

Next ping

05:00

No reveal yet.

Code or QR

4829

The runner’s screen shows a 4-digit code or a QR. Same proof either way. No “too far” gate when you are standing there. Sample shown, not scannable.

Optional Bluetooth

A hint when someone is close. Assist only. It never blocks a tag.

Jail and stealth

Caught runners go to jail. Free runners can jailbreak the group. Stealth hides a runner from the map while it is active.

Also in the app: zones of 1 km, 2 km or unlimited with optional shrinking, safe zones, compass, proximity haptics, and an OLED dark UI with appearance presets.

Build and download

Take a release or build it.

JDK 17. Android SDK 34. Android Studio Hedgehog or newer.

GitHub ReleasesSource
  1. 1

    Clone

    git clone https://github.com/dedsec-1337/MANHNT.git
  2. 2

    Open android/ in Android Studio

    Let Gradle sync.

  3. 3

    Run

    Pick a device or emulator and press Run.

Your own fork needs its own Firebase project: Anonymous Auth enabled, and your Realtime Database URL set in Constants.kt.

Safety and field rules

Play outside. Stay off roads. Don’t be an idiot.

  • Stay off roads.
  • Respect private property.
  • Keep GPS and mobile data on. Bluetooth is optional.
  • Parks, campuses and city blocks make good zones.
